# Ashes of Pantheon QA Tool 使用说明

## 连接 Unity Editor

1. 打开“连接”，点击“选择项目”，选择包含 `Assets`、`Packages` 和 `ProjectSettings` 的 Unity 项目根目录。
2. 点击“安装 Bridge”或“更新 Bridge”，切回 Unity 等待脚本编译完成。
3. 在“运行实例”中找到对应 Editor，点击“连接”。没有出现时，可点击该区域的“刷新”。
4. 未进入 Play Mode 时可浏览目录；进入 Play Mode 并加载战斗后，才能读取和编辑战斗状态。

所选路径自动保存。Editor Bridge 仅用于编辑器，不会进入 Player 构建。升级工具若包含 Bridge 改动，需再次点击“更新 Bridge”；只更新工具不会自动替换已安装的 Bridge。

选择项目、点击“连接”选项卡或窗口重新获得焦点时，工具会检查 Editor Bridge；也可点击“检查 Bridge 状态”。未安装时可安装，内置文件有差异或缺失时可更新，已与当前工具内置版本一致时按钮禁用。检测不会自动安装；版本号相同但文件内容不同时仍会提示更新，Unity 生成的 `.meta` 和文本换行差异不影响判断。

## 连接打包游戏

1. 在“连接”中点击“选择游戏包”，选择游戏 EXE 及其同名 `_Data` 文件夹所在目录。
2. 对支持的 Windows Mono 包点击“安装打包版 Bridge”。工具建立独立临时副本，原始游戏包不修改；IL2CPP 包目前不能通过此入口加载。
3. 点击“从临时副本启动”，在运行实例中连接该游戏，进入战斗。
4. 升级 Bridge 前先关闭临时副本中的游戏，重新安装打包版 Bridge，再启动。需要清理时点击“移除临时 Bridge”，不删除原始游戏。

连接丢失后，运行时编辑停止；已缓存的卡牌目录仍可离线浏览。顶部的连接名称和状态用于确认当前连接目标。

## 卡牌目录

鼠标悬停卡牌 1 秒显示名称、TypeId、费用和描述；键盘聚焦卡牌也可查看详情，Esc 关闭详情提示。

连接到有可用库存的场景后：

| 操作 | 普通卡牌 | 装备卡牌 |
| --- | --- | --- |
| 左键单击 | 获取 1 张手牌 | 前往战斗，并选中该装备等待放置 |
| 右键单击 | 删除 1 张手牌 | 删除同类已部署装备 |
| 聚焦后按 Delete | 与右键相同 | 与右键相同 |

金色圆标表示费用，青绿色“持有 ×N”表示数量。普通卡统计当前可见手牌，装备卡统计战场中已部署的同类装备，不等于全部牌库、弃牌或仓库数量。未连接或库存不可用时，增删操作不可执行。

## 搜索、筛选与排序

- 搜索框可输入中文名称、TypeId、标签或描述片段。删除搜索框内容可清空搜索。
- 类型、费用、稀有度可多选；同组内满足任一选项即可，不同组之间需同时满足。
- “清除 N 项”或无结果页面的“清除筛选”只清除筛选条件，不清除搜索文字。
- 排序字段可选 TypeId、类型、费用、稀有度；旁边箭头按钮切换升序和降序。

## 战斗地图与装备放置

左侧“场上对象”与中间“战斗地图”展示同一份运行时快照。单击列表对象或地图对象，在右侧检查器查看其状态。单击空格会选中格位，坐标显示在地图标题栏和放置按钮中。

放置装备：在左下方下拉框输入中文名称或 TypeId，选择结果，再选择地图目标格，点击“放置到 x, y”。下拉框也支持方向键选择、Enter 确认和 Esc 取消搜索。当前选中装备的名称和完整 TypeId 显示在下拉框下方；搜索文字本身不等于已更换选中装备。

放置成功后会重新读取游戏状态，装备同时出现在对象列表和地图。放置失败时检查反馈、格位及游戏当前阶段。部分中文缺失可能来自上游模板或本地化表缺失，请提供具体 TypeId 和实际游戏版本核对。

## 对象长按拖动

1. 在地图对象上按住鼠标左键 600 毫秒，对象上方显示长按百分比。
2. 进度完成后继续按住并拖到目标格，松开提交移动。普通短按只选中对象。
3. 绿色目标格表示前端未发现占用或越界；墙体及隐藏禁放规则仍由游戏最终复核。

支持主角、怪物和装备。只允许玩家可操作的空闲阶段，不消耗移动力，不逐格经过沿途位置。游戏结算中、目标被占用、越界、不可通行或装备禁放格会被拒绝。对象已经自行移动、消失或请求过期时，需要重新拖动。

提前松开、长按完成前明显移动鼠标、按 Esc、拖出地图、窗口失焦、切换选项卡会取消。也可以先选中对象，点击地图标题旁的移动图标，再单击目标格；方向键调整目标，Enter 确认，Esc 取消。旧 Bridge 不提供移动能力，需要更新后重新连接。

## 属性

主角提供“属性 / 祝福 / BUFF”，怪物提供“属性 / BUFF / 意图”。装备检查器显示实例及格位，不提供生命值和行动意图编辑。

在属性页修改主角的当前生命、最大生命、当前费用、最大费用，或怪物的生命、攻击力，点击“应用属性”提交。仅更改输入框不等于已经写入游戏。

“允许异常值”关闭时，生命值限制在 0 到最大生命之间，主角费用会在应用时限制到合法范围；打开后可进行异常数值测试，但游戏端仍可能拒绝不支持的值。

## 祝福

选中主角，打开“祝福”，在下拉框选中祝福后点击加号添加。条目同时显示中文名和 TypeId；已持有的同类祝福不能重复添加。点击条目右侧垃圾桶并确认移除。

祝福增删直接提交到运行实例，不需要再点“应用属性”。没有可用目录或正在处理时，相关控件禁用。

## BUFF

选中主角或怪物，打开“BUFF”，选择定义，填写层数和回合，点击“添加 BUFF”。实际是否支持叠层、持续回合由游戏中的 BUFF 定义决定。

持有列表展示当前层数及可用的持续回合信息。点击垃圾桶并确认可移除。装备不提供 BUFF 添加入口。

## 怪物意图

选中怪物，打开“意图”。从已注册意图中选择后点击加号；在条目中编辑可用参数，用上下箭头调整顺序，用垃圾桶删除。点击步骤序号设置循环起点，“清空”清除当前编辑序列。

这些操作先编辑工具内的序列，点击“应用序列”后才提交游戏。不支持任意底层 JSON。刷新或切换主工作区可能重新载入游戏快照，覆盖尚未应用的属性或意图编辑，请先提交需要保留的修改。

## 刷新与操作结果

顶部刷新按钮手动读取目录、战斗状态和持有数量。切换主选项卡、窗口重新获得焦点也会自动刷新；成功操作后的内部刷新不再额外弹出“刷新完成”。

同一操作的结果只在右下角显示一次，2 秒后自动消失，也可点击关闭。新消息替换旧消息并重新计时；成功、错误、信息和加载提示均遵循这一时长。消息消失不代表操作取消，仍在处理的控件会保持处理中状态，实际数据以游戏返回为准。

## 应用更新

在“连接”的“应用更新”中检查新版本，点击“下载更新”。工具优先使用匹配当前 ZIP 基础版本的文件级增量包，不匹配或增量校验失败时回退完整 ZIP。

下载、校验完成后点击“重启并更新”。更新不会调用安装器，会保留设置及用户文件。不要手动解压 `.delta.zip` 覆盖程序。0.1.3 及更早的单文件版需手动下载完整 ZIP 迁移一次。

下载进度、当前版本、连接状态属于持续状态，不会跟随右下角通知一起消失。更新助手异常或断电时，按更新页错误信息查看用户数据目录中的备份与结果记录，必要时重新解压完整 ZIP。
